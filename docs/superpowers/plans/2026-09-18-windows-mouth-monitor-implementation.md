# Windows 持续张嘴提醒工具实施计划

## 阶段一：项目骨架与领域逻辑

1. 创建标准 `src` 项目结构和 `pyproject.toml`。
2. 定义配置、校准资料、观察结果和状态枚举。
3. 拆出校准算法、状态机和提醒冷却逻辑。
4. 为领域逻辑添加单元测试。

## 阶段二：视觉与运行引擎

1. 封装摄像头扫描、打开和释放。
2. 封装 MediaPipe 模型与关键点映射。
3. 实现后台线程、10 FPS 节流和 MJPEG 调试帧。
4. 区分摄像头、黑帧、无人脸和模型错误。

## 阶段三：产品能力

1. 保存和加载 `%LOCALAPPDATA%\MouthMonitor\config.json`。
2. 实现双点校准持久化和重新校准。
3. 实现 Windows 系统提示音、冷却和测试提醒。
4. 增加摄像头选择、暂停、停止和设置接口。

## 阶段四：本地网页

1. 将原型页面迁移到正式包资源目录。
2. 增加摄像头扫描与选择。
3. 增加暂停、重新校准和测试提醒。
4. 展示持续时间、冷却、错误和非医疗说明。

## 阶段五：发布准备

1. 编写根 README、MIT LICENSE、CONTRIBUTING 和 `.gitignore`。
2. 添加 PyInstaller `onedir` 构建脚本。
3. 添加 GitHub Actions Windows 构建工作流。
4. 运行单元测试、源码启动测试和摄像头人工验证。
5. 尝试本机 PyInstaller 构建并检查产物。
